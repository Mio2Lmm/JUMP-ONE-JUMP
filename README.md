# JUMP-ONE-JUMP · 跳一跳助手

一个 Windows 上的「跳一跳」半自动辅助工具：右键点棋子、右键点目标，程序自动算出距离并长按左键跳跃。
附带一个网页控制面板（可选），可以启停助手、看日志、调参数。

**在线预览（仅界面演示，不能操作）：<https://mio2lmm.github.io/JUMP-ONE-JUMP/>**

> ⚠️ 注意：GitHub Pages 上那份只是前端页面，浏览器里没有 Python、没有桌面、碰不到你的游戏窗口，所以点按钮不会有任何真实动作。**要真的能跳，请下载本仓库的程序在本地运行，见下面第 1 节。**

---

## 1. 直接运行（推荐，不用装 Python）

1. 下载本仓库的 **`跳一跳助手.exe`** 和 **`config.json`**，放到**同一个文件夹**里（放桌面最省事）。
2. 打开「跳一跳」小游戏（微信小游戏或网页版均可），让游戏窗口露出来、别被遮挡。
3. 双击 `跳一跳助手.exe`，会弹出黑色命令行窗口，显示 `游戏区域 [...]，缩放 x.xxx`。
4. **鼠标移到棋子底部中心，单击右键** → 记下起点。
5. **鼠标移到目标平台中心，再单击右键** → 程序算出距离，自动长按左键跳跃。
6. 重复第 4、5 步继续下一跳；按 `Esc` 退出。

急停：把鼠标快速甩到屏幕左上角（PyAutoGUI FAILSAFE），或按 `Esc`。

> 右键只是用来取点，不会真的右键游戏；长按左键由程序发到游戏窗口，不会复位你的鼠标。

下载方式二选一：

- 网页：点开 `跳一跳助手.exe` → 右上角 **Download raw file**
- 命令行：

```bash
git clone https://github.com/Mio2Lmm/JUMP-ONE-JUMP.git
cd JUMP-ONE-JUMP
```

## 2. 参数调校

程序按「逻辑像素」计算：会把你游戏窗口的宽度缩放到 720 作为基准，所以换窗口大小不用重调。

| 现象 | 怎么改 |
|---|---|
| 跳过头 | 对应距离段的 `k` 减 0.02 ~ 0.05 |
| 没跳到 | 对应距离段的 `k` 加 0.02 ~ 0.05 |
| 整体差一点 | 调 `b`（毫秒偏移） |

`config.json` 按距离分三段（0-200 / 200-420 / 420-720），每段独立 `k`、`b`。
启动时程序会自动检测游戏窗口并写回 `GAME_REGION`，换电脑不用手改坐标。

## 3. 从源码运行（需要 Python 3.9+）

```powershell
pip install -r requirements.txt
python jump_assist.py
```

`python jump_assist.py --fit` 可以用 `cal.json` 里的历史样本自动拟合 `k` / `b`。

## 4. 网页控制面板（可选）

`server.py` + `ui/` + `启动UI.vbs` 是可视化面板：启停助手、看运行日志、改距离分段参数。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1
```

打开 `http://127.0.0.1:8765/`。这个面板本身也是 Python 写的，需要本机有 Python 环境；它只是「遥控器」，真正干活的是 `跳一跳助手.exe`。

想在外面（手机）也能控制，可以用 `start-tunnel.ps1` 走 Cloudflare 隧道，细节见 `外网访问.md`。

## 5. 常见问题

| 问题 | 原因 / 处理 |
|---|---|
| 双击 exe 被杀软拦下 | PyInstaller 打包常被误报，加白名单；不放心就用第 3 节从源码跑 |
| 提示「未找到游戏窗口」 | 窗口标题需含「跳一跳」或「微信」，且不能最小化；把窗口露出来后重开程序 |
| 右键没反应 | 必须把鼠标停在游戏窗口范围内再右键，程序只响应窗口内的右键 |
| 一直跳过头 | 见第 2 节，先把三段 `k` 各减 0.05 |
| exe 一闪而过 | `config.json` 必须和 exe 在同一目录 |
